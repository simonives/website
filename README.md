# Simon Ives | The Monopoly Engine

High-performance, static personal brand website for Simon Ives.

## Architecture
- **Host:** GitHub Pages
- **Stack:** Semantic HTML5, Vanilla JavaScript, CSS3
- **Design:** Modern Vanilla (Minimalist, frictionless)
- **Forms:** Pointed to Formspree (or equivalent static-friendly service)

## Deployment
Automated via GitHub Pages from the `main` branch.

## Maintenance
To update content, edit the corresponding `.html` file. Ensure that any changes maintain the "Architectural Dominance" and "Winning Productivity" aesthetic standards defined in the project mission.
